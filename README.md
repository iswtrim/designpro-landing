# DesignPro — Лендинг для онлайн-курса по UI/UX дизайну

Современный, полностью адаптивный одностраничный сайт (Landing Page) для вымышленного онлайн-курса «DesignPro». Проект создан для демонстрации навыков фронтенд-разработки, работы с анимациями и построения чистой компонентной архитектуры.

## ✨ Основной функционал

- **Адаптивная вёрстка:** Корректное отображение на любых устройствах (Mobile First).
- **Анимации при скролле:** Плавное появление секций с помощью Framer Motion.
- **Интерактивное модальное окно:** Форма записи на курс с блокировкой скролла и анимацией открытия.
- **Слайдер отзывов:** Карусель с адаптивным количеством отображаемых слайдов.
- **Мобильное меню:** Выдвижная панель навигации для мобильных устройств.
- **Кнопка «Наверх»:** Плавный скролл к началу страницы.

## 🛠 Стек технологий

- **React** (Vite) — быстрая сборка и компонентный подход.
- **Tailwind CSS** — utility-first стилизация, кастомные градиенты и тени.
- **Framer Motion** — сложные анимации, stagger-эффекты и переходы.
- **React Icons** — векторные иконки (Heroicons, FontAwesome).
- **Context API** — управление состоянием модального окна.
